# Metal-AD
Metal-AD is a large-scale, high-resolution dataset for industrial metal anomaly detection, featuring 21,837 images across 10 categories with precise pixel-level annotations. It introduces complex real-world challenges, including Multiple Defect Instances (MDI) and Multiple Defect Types (MDT), for robust model evaluation.
